# Wafa Alhayek — Living Archive

A static, no-build personal portfolio for collage, writing, and data analysis. Open `index.html` locally or deploy this folder to Cloudflare Pages.

## Included
- Responsive editorial homepage featuring `IMG_1175`, the Pulp Stiction submission piece
- Archive with the existing 46-item capture sequence and interactive viewer
- Nine supplied artworks exported as optimized WebP files in `img/web/` and duotone index plates in `img/duo/`
- Writing, Data, and About sections
- No framework or build step required

## Before publishing
1. Replace sample writing with your own text or remove entries that are not ready.
2. Replace data-project templates with real work or hide that section until ready.
3. Add a public contact email and any real social profile links.
4. Check all image credits/source notes.
5. Confirm the exhibition dates and link to the official Pulp Stiction page when available.
6. The nine supplied images are included; remaining archive entries use the designed fallback plate until their original exports are added.
7. Add a favicon and social sharing image, then connect `wafaalhayek.com` to the deployment.

## Deploy
Upload the contents of this folder to a Cloudflare Pages project as a static site. No build command is needed; the output directory is the project root.
